# Business Performance & Decision Lab

Interactive business-intelligence dashboard and what-if decision simulator,
built on the Online Retail II transaction dataset.

Stack: Python, pandas, SQLite, Streamlit, Plotly.

**Status:** work in progress (target: 31 October 2026).

## Dataset and attribution

- Dataset: *Online Retail II*, UCI Machine Learning Repository
- Link: https://archive.ics.uci.edu/dataset/502/online+retail+ii
- Licence: CC BY 4.0
- Changes made: cleaned and loaded into SQLite (documented in the Methodology page)
- TODO: paste the exact citation from the UCI page here

The data contains prices and quantities but **no product costs**, so any profit
shown in the simulator comes from a cost assumption entered by the user.
